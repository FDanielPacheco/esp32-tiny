# Firmware Documentation

This library's documentation is generated using Doxygen. Here's how to generate and view it:

### Prerequisites

You'll need Doxygen and Graphviz installed on your system.

**For Debian/Ubuntu-based systems:**

```
sudo apt install doxygen graphviz
```

### Generate and View it

Inside the docs folder, run doxygen without any extra flag.
```
doxygen
```
Open the documenation, by opening the `index.html` inside the docs/html folder
