uint8_t GPIO::mode ( uint8_t  pin,
uint8_t  state 
)

Selects the desired functional mode of the pin, can be either INPUT or OUTPUT, for the number of the pin refer to the datasheet.

Configures the mode of the specified GPIO pin as either input or output.

Parameters
[in]pinThe GPIO pin number to configure (0–39).
[in]stateThe desired mode for the pin. Options are:
  • INPUT : Configures the pin as an input.
  • OUTPUT : Configures the pin as an output.
Returns
One of the following values:
  • INPUT : If the pin is successfully configured as an input.
  • OUTPUT : If the pin is successfully configured as an output.
  • FAILURE : If the specified pin number is invalid (greater than 39).
Note
This function updates the appropriate GPIO enable register to set the pin mode.

◆ write()

uint8_t GPIO::write ( uint8_t  pin,
uint8_t  state 
)

Write to the PORT the desired state of the pin, can be either HIGH (Vcc) or LOW (Gnd)

Writes a specified state (HIGH, LOW, or TOGGLE) to the given GPIO pin.

Parameters
[in]pinThe GPIO pin number to write to (0–33).
[in]stateThe desired state for the pin. Options are:
  • HIGH: Sets the pin to a high logic level.
  • LOW: Sets the pin to a low logic level.
  • TOGGLE: Inverts the current state of the pin.
Returns
One of the following values:
  • HIGH: If the pin is successfully set to a high state.
  • LOW: If the pin is successfully set to a low state.
  • TOGGLE: If the pin's state is successfully toggled.
  • FAILURE: If the specified pin is invalid or not configured as an output.
Note
Validates if the pin is within range and configured as an output before performing the write operation.
