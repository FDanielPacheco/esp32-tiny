◆ infiniteLoopBreaker()

uint8_t infiniteLoopBreaker ( TIMER &  timer)

Waits for 100 us and then decrements the counter. Counter must be configured before using this function, it's necessary to reset by hand. (Example: tim0.counter = 100)

Parameters
[in]timerThe timer that will be counting the time, this timer needs to be initialized, and depending on the value when initialized, the delay might vary. Refer to TIMER documentation for more information.
Returns
  • 1: If the counter is greater than 0.
  • 0: If the counter is equal to 0.

References TIMER::counter, and TIMER::delay().
