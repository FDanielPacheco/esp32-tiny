uint8_t TIMER::check ( )

Checks if the alarm got triggered.

Checks whether the timer alarm has been triggered, indicating that the timebase has elapsed. If the alarm is triggered, the function rearms the timer by updating the relevant register.

Parameters
none
Returns
  • 1: If the timer alarm was triggered (time elapsed).
  • 0: If the timer alarm was not triggered (time not elapsed).

void TIMER::delay ( uint64_t  time)

This delay function halts the progress of the program, it receives as argument the time to wait.

Blocks the procedure of the code for the time specified.

Parameters
[in]timeThe desired delay time in microsseconds.
Returns
none
Note
  • If the time desired is smaller then the timebase, the delay will take the time of the timebase.
  • If the peripheral it's disable, the function will return immediately
  • If the TIMG_T_ALARM_EN is 0, the function will return immediately
